# CampusOS Design System Specification

## Color Tokens

### Surface & Backgrounds
- **App Background**: `#09090B` (`surface-bg`)
- **Card Surface**: `#18181B` (`surface-card`)
- **Borders & Dividers**: `#27272A` (`surface-border`)
- **Hover Surface**: `#27272A80`

### Brand Accent Palette
- **Primary Accent**: `#7C5CFC` (`brand-500`)
- **Primary Hover**: `#6938F9` (`brand-600`)
- **Accent Soft Glow**: `rgba(124, 92, 252, 0.15)`

### Status Indicators
- **Success / On-Track**: `#22C55E`
- **Warning / At-Risk**: `#F59E0B`
- **Danger / Urgent**: `#EF4444`

## Typography Hierarchy
- **Font Family**: Inter, Plus Jakarta Sans, system-ui
- **Page Titles**: `24px` - `30px`, Font Weight 700 / Bold
- **Section Headers**: `16px` - `18px`, Font Weight 600 / Semi-Bold
- **Body Text**: `14px`, Font Weight 400 / Normal
- **Captions & Badges**: `11px` - `12px`, Font Weight 500 / Medium

## Component Specs
- **Button**: 8px border radius, subtle hover scale (`active:scale-[0.98]`)
- **Card**: Glassmorphism blur (`backdrop-blur-xl`), 12px border radius
- **Input**: 8px border radius, `#09090B` dark fill, `#7C5CFC` focus ring
