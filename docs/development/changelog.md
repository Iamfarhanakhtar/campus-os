# CampusOS Changelog

## [1.0.0-phase0] — 2026-07-31

### Added
- Complete Phase 0 Foundation release.
- Feature-First architecture with self-contained feature modules.
- UI design system primitives inspired by Linear, Raycast, and Arc.
- Dark mode theme provider with `#09090B` background and `#7C5CFC` accent.
- Raycast-style Command Palette dialog (`⌘K`).
- Collapsible sidebar with navigation categories (*Home*, *Academics*, *Growth*, *Insights*, *System*).
- Complete TypeScript database models and PostgreSQL schema definitions.
- Full markdown documentation hierarchy in `docs/`.
