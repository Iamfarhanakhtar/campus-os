# Design Wireframes Repository

This directory contains low-fidelity and high-fidelity wireframes for CampusOS Phase 0 and future phases.

## Wireframe Index
- `01_dashboard_grid.png` — Main Operating System command center layout.
- `02_timetable_weekly.png` — Dynamic weekly schedule and room allocation matrix.
- `03_attendance_calculator.png` — Safe missable class buffer calculation UI.
- `04_ai_study_hub.png` — Focus zone, Pomodoro timer, and AI flashcard generator.
