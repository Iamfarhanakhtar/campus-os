# 🎓 CampusOS

> Organize. Learn. Grow.

CampusOS is a modern AI-powered College Operating System designed to help students manage their academics, attendance, projects, study plans, and career growth through a beautiful and intelligent dashboard.

---

## ✨ Features

- 📅 Smart Timetable
- 📊 Attendance Tracker
- 📝 Daily Planner
- 🎯 Goals
- 📚 Study Hub
- 💻 Project Tracker
- 📈 Analytics
- 🤖 AI Coach
- 📂 Notes
- 🌙 Dark Mode

---

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase
- TanStack Query
- React Router
- Framer Motion
